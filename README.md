# Vivek Vardhan Mamidala — Portfolio

Static site: Home, About, and 3 Artifact pages. No build step — plain HTML/CSS/JS.

## Deploy to GitHub Pages

1. Create a new repo on GitHub (e.g. `portfolio` or `<username>.github.io` for a root domain).
2. Upload all files in this folder to the repo root (keep the `css/`, `js/`, `images/` folders as-is).
3. In the repo: **Settings → Pages → Source → Deploy from branch → `main` / root**.
4. Save. Your site will be live at:
   - `https://<username>.github.io/<repo-name>/` (normal repo), or
   - `https://<username>.github.io/` (if the repo is named `<username>.github.io`)
